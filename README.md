# 在哪见｜群体会面 AI 推荐系统

「在哪见」面向多人聚会选址场景，将参与者的位置、交通方式、预算和偏好汇总，展示 Top 3 候选地点及推荐理由，帮助大家通过投票确定见面地点。

## 体验产品

直接打开 [产品展示页](./index.html)，可查看项目背景、产品亮点和五步使用流程，并操作内嵌的 H5 原型。原型支持创建聚会、填写偏好、模拟好友加入、查看推荐及投票等演示流程。

下载并解压本项目后，也可以在 Chrome、Edge 等现代浏览器中双击 `index.html` 打开，无需安装依赖或运行构建命令。

## 演示范围

本项目提供产品展示页与前端交互原型。好友加入、地点推荐和投票用于演示产品流程；真实跨设备协作、实时商户数据和路线服务尚未接入。部分字体、图片和头像来自外部资源，离线打开时这些视觉资源可能无法显示。
